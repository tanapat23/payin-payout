# PayIn PayOut

บอท Telegram สำหรับจดบันทึกรายได้ / รายจ่ายรายวัน (สำหรับคนขับ Grab) พร้อมเว็บแดชบอร์ดสรุปรายสัปดาห์ / รายเดือน

## วิธีใช้งานผ่าน Telegram

1. เริ่มแชทกับบอท พิมพ์ `/start`
2. กดปุ่ม **"เริ่มบันทึก"** เมื่อเริ่มวันทำงาน
3. เมื่อได้เงินจากออเดอร์ กดปุ่ม **"รายได้"** แล้วพิมพ์จำนวนเงิน (เช่น `21`) แล้วส่ง
   - ถ้าออเดอร์นั้นได้เพชรจากเควสรายวันของ Grab ด้วย ให้พิมพ์ **"จำนวนเงิน เว้นวรรค จำนวนเพชร"** เช่น `21 35` (ได้ 21 บาท + เพชร 35) บอทจะสะสมเพชรของวันนั้นให้อัตโนมัติ และแจ้งว่าตอนนี้อยู่ระดับไหน เทียบกับเป้าของ Grab (จันทร์-ศุกร์ 435/515/615/725, เสาร์-อาทิตย์ 480/560/655/775 สำหรับระดับ 1-4)
4. มีรายจ่าย กดปุ่ม **"รายจ่าย"** แล้วพิมพ์จำนวนเงินเช่นกัน (ไม่มีเพชร) — ทำซ้ำได้หลายรายการต่อวัน
5. จบวันแล้วกด **"จบการบันทึก"** ระบบจะถามยืนยันอีกครั้ง กด **"ยืนยัน"** แล้วบอทจะสรุปยอดรายได้ / รายจ่าย / คงเหลือ / เพชรสะสม ของวันนั้นให้ทันที

ยอดรวมของทุกวันจะถูกเก็บไว้ถาวรเพื่อดูสรุปย้อนหลังแบบรายสัปดาห์ / รายเดือนผ่านหน้าเว็บ (ไม่ต้องกรอกอะไรเพิ่มผ่านเว็บ — กรอกผ่าน Telegram อย่างเดียว) แต่ **รายการย่อยแต่ละออเดอร์ของวันที่ปิดบันทึกไปแล้วจะถูกลบทิ้งทันทีที่กด "จบการบันทึก"** เพื่อไม่ให้ข้อมูลสะสมเปลืองพื้นที่ — เก็บไว้แค่ยอดรวมรายวัน (รายได้ / รายจ่าย / เพชร / ระดับ) เท่านั้น ดูรายการย่อยแบบเรียลไทม์ได้เฉพาะวันที่ยังไม่ปิดบันทึก

## การติดตั้ง (รันในเครื่องตัวเอง)

ต้องมี [Node.js](https://nodejs.org/) เวอร์ชัน 18 ขึ้นไป

```bash
npm install
cp .env.example .env
```

แก้ไฟล์ `.env`:

- `TELEGRAM_BOT_TOKEN` — token จาก [@BotFather](https://t.me/BotFather)
- `ALLOWED_CHAT_ID` — (แนะนำให้ตั้ง) chat id ของคุณ เพื่อไม่ให้คนอื่นใช้บอทนี้ได้ วิธีหา: รันบอทขึ้นก่อน แล้วพิมพ์ `/whoami` คุยกับบอท จะได้ chat id มาใส่ในไฟล์ `.env` แล้วรันใหม่
- `WEB_PORT` — พอร์ตของเว็บแดชบอร์ด (ค่าเริ่มต้น 3000)
- `WEB_USERNAME` / `WEB_PASSWORD` — ตั้งรหัสผ่านป้องกันหน้าเว็บ (แนะนำให้ตั้งเสมอถ้าจะเปิดให้เข้าถึงจากอินเทอร์เน็ต) เปิดหน้าเว็บครั้งแรกเบราว์เซอร์จะเด้งถามชื่อผู้ใช้/รหัสผ่าน ถ้าปล่อยว่างจะไม่มีการป้องกันเลย

รันระบบ (ทั้งบอทและเว็บพร้อมกัน):

```bash
npm start
```

เว็บแดชบอร์ดจะเปิดที่ `http://localhost:3000`

## เปิดเว็บแดชบอร์ดให้เข้าถึงได้จากอินเทอร์เน็ต

เพราะระบบรันอยู่ในเครื่องคุณเอง การจะเปิดหน้าเว็บให้เข้าถึงได้จากที่อื่นต้องใช้ tunnel เปิดพอร์ตออกไปอินเทอร์เน็ต (เครื่องต้องเปิดและรัน `npm start` + tunnel ค้างไว้ตลอดเวลาที่ต้องการให้เข้าดูได้)

**ใช้อยู่ตอนนี้: ngrok (ลิงก์คงที่ ไม่เปลี่ยน)**

บัญชี ngrok ฟรีทุกบัญชีจะมี "dev domain" คงที่ให้อัตโนมัติ 1 โดเมน (ดูได้ที่ [dashboard.ngrok.com/domains](https://dashboard.ngrok.com/domains) — ชื่อจะถูกสุ่มมาให้ เลือกเองไม่ได้ถ้าไม่อัปเกรดเป็นแผนเสียเงิน) รันด้วยคำสั่ง:

```bash
ngrok http 3000 --url=https://<โดเมนของคุณ>.ngrok-free.dev
```

ลิงก์นี้จะคงที่ถาวรทุกครั้งที่รัน ไม่ต้องตั้งค่าใหม่ (ต้อง `ngrok config add-authtoken <token>` ครั้งแรกก่อน โดย token ดูได้ที่ [dashboard.ngrok.com/get-started/your-authtoken](https://dashboard.ngrok.com/get-started/your-authtoken))

**ทางเลือกอื่น: Cloudflare Tunnel (ฟรี แต่ลิงก์เปลี่ยนทุกครั้ง)**

```bash
cloudflared tunnel --url http://localhost:3000
```

ได้ลิงก์ `https://xxxx.trycloudflare.com` ใช้งานได้ทันทีไม่ต้องสมัครบัญชี แต่ลิงก์จะสุ่มใหม่ทุกครั้งที่รัน เหมาะกับการเปิดใช้ชั่วคราว

> ถ้าต้องการลิงก์ที่ตั้งชื่อเองได้ และไม่อยากเปิดเครื่องค้างไว้ตลอด ค่อยพิจารณาย้ายไป deploy บน VPS/Cloud หรืออัปเกรดแผน ngrok/Cloudflare ในอนาคตได้ — โครงสร้างโค้ดรองรับอยู่แล้ว (ข้อมูลเก็บเป็นไฟล์เดียวที่ `data/db.json`)

## โครงสร้างโปรเจกต์

```
src/
  index.js     — จุดเริ่มรันทั้งบอทและเว็บ
  bot.js       — ลอจิกบอท Telegram (ปุ่ม, สถานะการบันทึก)
  server.js    — REST API + เสิร์ฟหน้าเว็บแดชบอร์ด
  db.js        — เก็บ/อ่านข้อมูล (ไฟล์ JSON ที่ data/db.json)
  dateUtils.js — จัดการวันที่/เวลาโซน Asia/Bangkok (UTC+7)
public/
  index.html   — หน้าเว็บแดชบอร์ด (กราฟ + ตารางสรุปรายสัปดาห์/รายเดือน)
data/
  db.json      — ฐานข้อมูล (สร้างอัตโนมัติ, ไม่ถูก commit เข้า git)
```

## หมายเหตุเรื่องความปลอดภัย

- ควรตั้งค่า `ALLOWED_CHAT_ID` เสมอ ไม่เช่นนั้นใครก็ตามที่รู้ username ของบอทจะสามารถคุยกับบอทและบันทึก/ดูข้อมูลได้
- ควรตั้งค่า `WEB_USERNAME` / `WEB_PASSWORD` เสมอถ้าเปิดหน้าเว็บให้เข้าถึงได้จากอินเทอร์เน็ต (ผ่าน ngrok/Cloudflare Tunnel) ไม่เช่นนั้นใครก็ตามที่มีลิงก์จะเห็นข้อมูลรายได้-รายจ่ายทั้งหมดได้
